# Dataset

The notebook expects two CSV files:

- `Client.csv` — customer profile and demographic information
- `Record.csv` — usage statistics, calls and revenue information

The notebook merges the files using `Customer_ID` when that column is present in both datasets.

## Important

The CSV files are **not included** in this GitHub repository package.

Before running the notebook, obtain the dataset from the permitted/original source and place the files where the notebook can access them.

Do not upload a dataset to GitHub unless its license explicitly permits redistribution.
